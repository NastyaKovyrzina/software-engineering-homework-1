# ML-проекты: Анализ различных модальностей данных

## Описание проекта

Данный репозиторий содержит решения четырёх задач машинного обучения для работы с различными типами данных: текст, аудио, изображения и видео. Все решения реализованы на Python с использованием современных предобученных моделей и фреймворков (PyTorch, Hugging Face Transformers).

---

## Задачи

### Задача 1: Определение тональности текстовых отзывов (NLP)
- **Цель:** Бинарная классификация отзывов на русском языке (POSITIVE/NEGATIVE)

### Задача 2: Преобразование речи в текст (ASR)
- **Цель:** Автоматическая транскрибация русской речи в текст

### Задача 3: Распознавание объектов на изображениях (Object Detection)
- **Цель:** Обнаружение объектов с построением ограничивающих рамок (bounding boxes)

### Задача 4: Распознавание действий на видео (Video Understanding)
- **Цель:** Классификация человеческих действий в видеопоследовательности

---

## Технологии

- **Python 3.10+**
- **PyTorch** — основной фреймворк для всех задач
- **Hugging Face Transformers** — загрузка и использование предобученных моделей
- **OpenCV** — обработка изображений и видео
- **scikit-learn** — расчет метрик качества
- **pandas** — работа с датасетами
